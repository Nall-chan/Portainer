# Diese Library: Portainer  

- Diese Library dient zur Anbindung von Portainer, an die Software IP-Symcon. Sie stellt die notwendigen Module und Funktionen bereit, um Portainer-Instanzen in IP-Symcon zu integrieren und zu steuern.
- Die Library ist so konzipiert, dass sie leicht erweiterbar ist, um fehlende Abschnitte bei der Erweiterung der Portainer API zu ergänzen.
- Der API von Portainer ist hier verfügbar: `https://docs.portainer.io/api`
- Die Docker API ist über `https://docs.docker.com/reference/api/engine/version/v1.56/` verfügbar.
